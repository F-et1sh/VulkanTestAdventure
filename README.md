## About

**VulkanTestAdventure** is a sandbox to learn Vulkan.
There is almost nothing to look at. The project is very polluted, but it's fulfilled its purpose : helped me with Vulkan in [Forr-Engine](https://github.com/F-et1sh/Forr-Engine).\
